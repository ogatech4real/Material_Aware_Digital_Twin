# Data

Raw datasets are intentionally excluded from this repository because of file-size and third-party data-distribution considerations.

The experiments use external data sources including:

- **UK-DALE** residential electricity-demand data.
- **PVGIS** meteorological and photovoltaic data.

Users wishing to reproduce experiments requiring these datasets should obtain them directly from their original providers and comply with the applicable licences and citation requirements.

Generated and processed research outputs are retained separately under `results/`.
